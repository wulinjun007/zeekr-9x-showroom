# ZEEKR 9X 本轮补充与需求对照

2026-09-09。范围：当前单车型本地 Three.js 展厅；参考四份用户文档。表中的“已有”是代码/资产层面的覆盖，不等于完成实车还原或全部视觉验收。

## 本轮接入

- 默认黑色车漆、黑色夜景，驶入期间保留夜景并开启灯组；显式分享链接的日景/车色保留。
- 模型与当前场景着色器预热后开始驶入；驶入之后自动环绕；可跳过、重播，减少动态效果偏好仍受尊重。
- 画质：自动、流畅、均衡、精细。自动档初始参考设备线程数/可用内存提示，最终依持续帧耗时升降；手动档不会被自动改回。浏览器记住选择，存储不可用时仍可当次使用。
- 限制渲染像素预算，静止时暂停渲染；热点独立更新，整车静态部件合批。开门、分件拆解、隐藏、透明和材质切换仍恢复原有可操作部件。
- 轮组/灯组近景；选择轮毂和轮胎时自动聚焦轮部，拖动可打断运镜。
- HMI 改为车速/挡位、车辆与感知图形、主行动提示、次级遥测四层。接管和紧急告警突出显示；车门与安全带状态读取当前设置。仍是 HMI 概念界面，不标称原厂 OS 复刻。
- 保存/恢复方案：当前浏览器保存车漆、轮组、内饰材质、天气、座位/身高、机位预设、HMI 场景及时间轴进度。恢复后暂停。分享链接也补上时间轴进度。
- 场景重置保留车漆、轮组、CMF 与身高；原有全部重置入口保留。

## 最需后续资产工作的四项

1. 顶棚和门上沿：原始烘焙图集模糊不能靠提高像素倍率修复。需要 Blender UV/贴图、缝线和零件边缘修整，导出再比对。
2. 人车完整动作：示意人不等于人物动画；需要带骨架角色、门槛接触点、手脚约束和安全带绑定。
3. 独立座椅与装载：当前合并网格不能假装支持所有单座动作；需分离座椅、靠背、腿托和滑轨。
4. 城市/极端驾驶/碰撞：现有动态为展示模型。需新增道路与道具资产；真实碰撞能力必须使用可核验的试验或工程数据，不能由视觉动画推断。
