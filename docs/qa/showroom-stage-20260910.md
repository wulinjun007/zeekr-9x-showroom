# 车辆展示空间 · 2026-09-10

## 设计依据

参考 [PUBG MOBILE × Bentley 官方车辆联动展示](https://www.pubgmobile.com/en/event/BentleyCollab/) 的车辆主角、材质化地面和多层空间构图。采用原创石材展台与弧形灯光建筑，不使用对方图片、模型或纹理资源。

夜晚采用石墨灰、低饱和冷暖光和金属嵌线；白天保留中性灰展厅。程序化石材细法线、分缝、接触阴影和远处渐变均在现有渲染管线中完成。新增阴影是艺术化接触阴影，不是真实光追反射。

## 性能与隔离

- 新增 10 次绘制调用、1,764 个三角面、1 张 256² RGBA 法线贴图及 mipmaps。
- 不新增实时灯光、阴影贴图、反射渲染通道、远程背景资源或持续动画。
- 展厅在车内、驾驶场景、底盘、拆解、道路模拟及雨雪等天气下隐藏；接触阴影跟随入场位移。
- 原有自动画质、像素预算、静止停绘和车辆交互继续使用。

## 验证

通过 TypeScript 检查、Vercel 构建、render-performance.mjs 与 showroom-stage.mjs。浏览器切换白天、夜晚、车内、驾驶场景后未捕获脚本或着色器错误。
