# 2026-09-09 版本快照

版本标签：`v0.2.0-20260909`。保存当前本地展厅代码、GLB 模型、贴图、来源清单、功能检查及需求对照文档。

## 恢复网页项目

```sh
git clone https://github.com/wulinjun007/zeekr-9x-showroom.git
cd zeekr-9x-showroom
git checkout v0.2.0-20260909
npm ci
npm run dev -- --port 3001
```

需要有私有仓库访问权限。使用 Node.js 24。模型和网页贴图已在 Git 中，不需要额外下载原站模型。官方参考视频仍由原站提供。

## 当前版本内容

- 默认黑车夜景、驶入/环绕、回放、手动接管相机。
- 自动/流畅/均衡/精细画质，静态合批、按需渲染与独立热点更新。
- HMI 信息层级、轮组/灯组特写、方案保存/恢复、保留配置的场景重置。
- 原有开门、CMF、天气路面、六位置乘坐、部件拆解与25个场景。

## Blender 源工程备份

本版本 Release 随附 `zeekr-9x-blender-sources-20260909.zip`：两份当前原生 Blender 工程、材质资源、相关处理脚本和检查记录。压缩包保留 `outputs/` 与 `work/materials/` 的相对结构。`BACKUP-MANIFEST.json` 记录文件校验值。

网页使用 Git 中现有 GLB；原生座舱精修工程尚未完成全部烘焙/导出同步，二者不应混为同一版。部分 Blender 脚本带本机绝对路径，换电脑执行前须按恢复目录调整；本次备份不重新执行建模脚本，也不声称已校验所有 Blender 外部路径。
