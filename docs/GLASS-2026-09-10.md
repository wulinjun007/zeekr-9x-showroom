# 分区玻璃与隐私配置 · 2026-09-10

入口：外观 / 车内空间 → 更多选配 → 玻璃与隐私。

- 五种色调：原色、烟灰、冰蓝、茶铜、墨绿。
- 三个独立视觉通透度滑杆：前挡/前排、后排/后挡（含后三角窗）、全景天幕，范围 0–100。
- 全景通透、均衡遮光、后排隐私、私享座舱四个预设；隐私预设保留前挡通透。可恢复模型默认玻璃。
- URL 分享、保存/恢复方案及场景重置保留个性化玻璃设置。旧链接使用原模型默认透明度；非法颜色和数值受解析校验。
- 只修改车窗/天幕玻璃；不染色灯罩或车机屏幕。整车透视模式暂时使用透视透明度，退出后恢复玻璃配置。
- 车内环境补光随三组玻璃的通透设置轻微调整，属于艺术化透光表现，不是实测透光率、光学仿真或贴膜规格。
- 复用现有玻璃材质，无额外贴图、模型、实时折射 pass。玻璃滑杆仅更新缓存的玻璃材质列表，避免刷新全车材质。
- 支持现有五种语言，预设/色调使用可访问选中状态，三个滑杆支持键盘操作。

验证：TypeScript、Vercel 构建、配置往返、非法参数、灯罩排除、分区/预设、保存恢复与场景重置检查通过。浏览器实际检查通透→后排隐私差异、后排滑杆至 0、茶铜色切换；控制台无脚本错误。
