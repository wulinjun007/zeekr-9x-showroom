# 车灯开关对比优化 · 2026-09-10

- 前灯发光强度由 2.2 调至白天 4.5 / 夜晚 6，尾灯调至 3.2；关闭时灯芯底色压暗，改善开关对比。
- 前灯增加两个 64×64 程序纹理的局部光晕，不使用全屏 Bloom 或额外阴影贴图；侧后方自动衰减。
- 两个现有聚光灯改为跟随实际 DLP 灯组位置，白天强度 20、夜间 65；开启后地面形成明显照明区。
- 光晕与照明随车辆入场及驾驶位移移动；拆解、透明、隔离及隐藏灯组时不显示固定投光。
- 本地浏览器检查夜晚开关灯、白天开灯及车尾灯带，脚本错误日志为空。TypeScript 与 Vercel 构建通过。

这是交互展示照明调校，不代表真实车辆灯具光学测试数据。
